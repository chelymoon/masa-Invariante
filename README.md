# masa-Invariante
Cuando los protones chocan, en ocasiones crean un Bozón Z, el principal detalle es que esta partícula es muy inestable, ya que apenas si vive una fracción de segundo de unos 10^-25 segundo antes de desintegrarse
El objetivo principal en el análisis de la desintegración del Bosón Z a dos muones (Z $\rightarrow \mu\mu$) es reconstruir la masa invariante de las partículas resultantes.
